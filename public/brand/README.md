# Brand Assets & Identitas Visual

Direktori ini berisi seluruh aset resmi identitas visual (logo & branding) untuk website portofolio **Ahmad Ridho Syafaat** dengan tema **Neo-Brutalism**.

---

## 1. Master Logo Vektor (SVG)
- `brand-symbol.svg` : Simbol utama (*The Spark Pivot*) berupa ubin squircle kuning dengan elemen bar data dan bintang AI sparkle.
- `brand-horizontal.svg` : Logo horizontal lengkap (simbol grafis + tipografi vektor *RIDHO* + lencana *DATA • PRODUCT [AI]*).

## 2. Varian Warna Simbol
- `brand-symbol-black.svg` : Versi hitam satu warna (*single-color black*).
- `brand-symbol-white.svg` : Versi putih untuk latar belakang gelap (*reversed/dark mode*).
- `brand-symbol-mono-ffd60a.svg` : Versi monokrom kuning aksen Neo-Brutalisme.
- `brand-symbol-mono-2563eb.svg` : Versi monokrom biru elektrik.
- `brand-symbol-square.svg` : Simbol di atas kanvas 256x256 untuk avatar dan profil media sosial.
- `brand-symbol-app-icon.svg` : Simbol dalam format app-tile.

## 3. Web & Favicon Kit
- `favicon.ico` : Format multi-resolusi untuk kompatibilitas browser lama.
- `favicon.svg` : Ikon vektor modern untuk tab browser beresolusi tinggi.
- `favicon-16.png`, `favicon-32.png`, `favicon-48.png` : PNG favicon berbagai ukuran standar.
- `apple-touch-icon.png` (180x180) : Ikon bookmark untuk perangkat Apple iOS/iPadOS.
- `icon-192.png`, `icon-512.png`, `maskable-512.png` : Ikon aplikasi web progresif (PWA) dan Android.
- `site.webmanifest` : Konfigurasi manifest instalasi aplikasi web.
